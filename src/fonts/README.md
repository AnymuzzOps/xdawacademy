# Fuentes locales

Anton Regular e Inter Variable proceden de `google/fonts`, directorios `ofl/anton` y `ofl/inter`, bajo SIL Open Font License. Se incluyen ambas licencias y se conservan sus nombres originales en los metadatos.

Se generaron subconjuntos WOFF para caracteres latinos, acentos españoles y signos de puntuación. `Academy Display` es únicamente el alias CSS local para Anton. La Home no requiere conexiones a Google Fonts.

Anton reproduce la dirección condensada de los títulos de las capturas. Sin acceso al archivo fuente de Figma no se afirma que sea su tipografía exacta; la selección se basa en la referencia visual.
