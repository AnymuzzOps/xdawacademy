# Imágenes locales de referencia

Estas tres escenas fueron generadas con IA para aproximar las fotografías de las capturas de diseño facilitadas. **No son fotografías oficiales de XDAW** ni imágenes extraídas de Figma. No representan a instructores o participantes reales. La procedencia se indica también en `/legal/` y se enlaza desde el footer.

| Archivo | Escena | Dimensiones | Uso |
| --- | --- | --- | --- |
| hero.webp | Instructora guiando un grupo | 1536 × 1024 | Hero desktop/tablet |
| hero-small.webp | Misma escena | 900 × 600 | Hero móvil |
| metodologia.webp | Grupo aprendiendo una secuencia | 1100 × 825 | Metodología desktop/tablet |
| metodologia-small.webp | Misma escena | 640 × 480 | Metodología móvil |
| comunidad.webp | Grupo compartiendo una práctica | 1100 × 825 | Comunidad desktop/tablet |
| comunidad-small.webp | Misma escena | 640 × 480 | Comunidad móvil |

Los originales de generación permanecen fuera del repositorio. Los WebP publicados se codificaron a calidad 80–83, con dos tamaños y un total aproximado de 530 KB. No dependen de URLs externas.

Para incorporar las fotos originales aprobadas, sustituir ambas resoluciones de cada escena y actualizar dimensiones y alt de sus elementos `picture`/`img`. Revisar el foco desktop/móvil y el contraste de los pies; eliminar la advertencia de IA de `/legal/` solo cuando ya no se utilicen estas imágenes.
